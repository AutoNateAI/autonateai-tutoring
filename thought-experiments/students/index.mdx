# Students

This library is for learners who want to build confidence with AI, structured thinking, and practical problem solving.

## What Is In This Library

- **Easy:** low-friction missions that teach clean thinking and reliable execution.
- **Medium:** applied scenarios where structure, routing, and system logic start to matter.
- **Hard:** more demanding builds that combine multiple ideas under pressure.

## Difficulty Levels

## 🟢 [Easy](/thought-experiments/students/Easy/)
Build the basics of graph thinking, path finding, and workflow clarity.

## 🟡 [Medium](/thought-experiments/students/Medium/)
Work through more realistic missions where multiple constraints must be handled at once.

## 🔴 [Hard](/thought-experiments/students/Hard/)
Train deeper systems reasoning through longer, higher-stakes scenarios.
