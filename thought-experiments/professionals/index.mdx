# Professionals

This library is for professionals who want AI workflows they can actually use in real work, not just experiment with.

## What Is In This Library

- **Easy:** practical workflow upgrades for daily operations.
- **Medium:** orchestration patterns that connect multiple tools and steps.
- **Hard:** higher-stakes systems thinking, resilience, and production-style architecture.

## Difficulty Levels

## 🟢 [Easy](/thought-experiments/professionals/Easy/)
Use AI to remove friction from recurring work and make systems more organized.

## 🟡 [Medium](/thought-experiments/professionals/Medium/)
Connect tools, agents, and structured outputs into stronger working pipelines.

## 🔴 [Hard](/thought-experiments/professionals/Hard/)
Go deeper on security, resilience, and more advanced implementation patterns.
